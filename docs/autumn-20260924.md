## 协议依据

SVIP 商品 1053 为免费化肥，1054 价格为 110 钻石，1055、1056 分别使用 1901、1902 碎片兑换。非会员可以浏览该分页，前后端均禁止购买。会员自动礼包流程仅领取满足免费条件的商品。

祈愿领奖使用服务端待领奖状态的 `choose_id`。快乐分享操作只调用活动 RPC，每日首次奖励后禁用按钮；不发送 QQ 消息，不代替他人点击，也不调用需要 Ark 点击上下文的 op 72。

快乐日志“我领取的”使用 tab 1，“领取我的”使用 tab 0，与实际请求和官方页面一致。每日领取与分享分别对应日志 kind 4、3；网页仅接收所需的日志及奖励字段，不返回 Ark 分享凭据。

桂月华庭礼包 1060 的原价为 880 钻石，实际回包的限时价格为 780，促销时间为 `1790179200 <= serverTime < 1790783999`。页面显示当前价格及划线原价，后端按服务器时间重新校验价格；提交的确认价格与最新价格不一致时返回 `MALL_PRICE_CHANGED`，不会按过期报价直接购买。验证仅使用回包和模拟购买，未实际消费钻石。

两个活动入口使用官方小图标，总计 28,692 bytes；来源和哈希见 `core/src/activity-data/autumn-assets.json`。页面主体使用 CSS，新增物品使用小图标。

两个新页面的操作通知复用项目 toast，成功领取和操作失败使用浮动提示；刷新与读取日志成功时不显示通知，不插入撑开页面的提示条。
