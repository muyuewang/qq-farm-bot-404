# 萌宠成长日记适配与本地验证（2026-09-10）

接入活动目录、比熊之家、爪印手记、拾物小铺、节令小礼、宝藏护送和游戏商城的活动商品筛选。本文记录上游活动分支的实现、协议来源与本地验证范围。

## 协议与资源来源

- 协议依据活动真实抓包及官方小程序 encoder / decoder；用于回归的消息体与预期字段保存在 `core/tests/fixtures/pet-*.json`。
- 当前 QQ 小程序 `1.14.1.10`，实际登录版本 `1.14.1.10_20260916`。
- 活动分组 `2026090100`，主活动 `2026090101`，种子赠礼 `2026090102`，拾物小铺 `2026090103`。
- `core/src/proto/pet-diary.proto` 按官方 encoder / decoder 的字段号、类型及嵌套消息实现。真实请求与编码结果逐字节一致，真实响应的全部已定义字段与官方 decoder 逐项比较；未使用响应字节数推断含义。
- 活动业务图像位于 `web/public/activity-assets/pet-diary/`。`core/src/activity-data/pet-diary-assets.json` 记录 27 项资源的原始路径、官方 CDN URL、原始 PNG 的 SHA-256、本地 WebP 的 SHA-256 与编码参数；所有 `sha256` 与本地文件逐一匹配。
- 手记页改成自绘纸感卡片墙：未解锁用虚线占位加爪印，解锁后显示服务端下发的手记照片（`img_s3PhotoWall_photo*`）。页内原先自拟的装饰文案已移除。
- 照片相框按原图比例 `aspect-ratio: 539 / 774` 固定，图片用 `object-fit: contain` 完整显示，不再裁切；相框高度随比例确定，修复图片被网格固有高度撑大后裁掉下半部分的问题。

- 多份已完成奖励按道具合计。只有状态 3 或状态 2 且有效结束时间已到时才可领取；服务端操作前再次核对。等待中的宝藏、结束时间 0 和重复领取均不会发送领奖请求。
- 日志使用真实命令 44，保留时间、挑战方、挑战书、等级、对应宝藏、双方锦囊、胜负、假宝藏标记及增加/减少的道具。互动记录和被挑战记录分开保存，避免切换页面时互相覆盖。

## 操作一致性与资源限制

- 一键务农确认文案简化为“确定要一键务农吗？”，移除随活动变化而过时的固定清理项目列表。
- 活动操作共用串行写入队列，执行前重新查询活动状态和库存，检查每日次数、领取状态、限购和成本；成本按同币种合并后验证。
- 活动兑换拒绝钻石成本和钻石替代成本。锦囊付费刷新在串行操作内重新核对次数和点券库存，余额未知、点券不足、达到上限、尚未完成选择时均不发送付费请求。面板提交明确的免费/点券意图及预期付费次数，旧免费点击不会升级为收费，旧付费次数不能重复使用；拒绝钻石覆盖参数。官方命令 41 的请求体仍为空，面板前置校验参数不会发给游戏服务端；协议不提供币种锁，无法阻止其他客户端并发消费导致的服务端币种变化。
- 操作成功但随后刷新失败时，明确返回成功与刷新失败信息，前端暂停继续消耗，避免误重试。账号切换会清空详情，并丢弃旧账号尚未返回的结果。
- 萌宠查询与操作的 worker 超时已按串行 RPC 调整，避免被原先 10 秒 IPC 超时提前截断。
- 比熊成年后的永久宠物目录已加入 `90031`、官方头像、活动获得方式和技能“比熊润田”。服务端尚未返回该宠物时，宠物页仍显示“未获得”；拥有、上场状态仅由真实宠物响应决定，活动成年不会自行伪造已拥有状态。
